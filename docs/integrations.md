- **Authenticate** (OAuth, API keys, headless signup): https://docs.thingery.dev/authentication
- **First workflow** (buying and selling): https://docs.thingery.dev/guides/buying and https://docs.thingery.dev/guides/selling
- **Troubleshooting**: https://docs.thingery.dev/reference/troubleshooting
